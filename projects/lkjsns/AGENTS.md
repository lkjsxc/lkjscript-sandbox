# lkjsns agent guidance

Use the checksum-pinned public lkjscript 0.1.89 runtime. Change application behavior
through public draft/plan/apply operations; do not edit canonical graph state or
substitute a Node/Python application server. Product rendering, forms, admission,
authentication, social behavior and media access remain native lkjscript.

Keep every product-owned label, message, title and accessibility name in English.
User-authored content may use any language. Preserve exact CSS/native-asset byte
equality. The selected bundle must match the complete source-input file set; any
changed native fragment, stylesheet, operations script or configuration needs a
fresh build. A successful build is not proof of browser behavior or publication.

The owner explicitly authorized replacing the legacy public service on 2026-10-11.
Legacy migration and compatibility are not required. Preserve unrelated services,
unrelated worktrees and secrets. Never expose a synthetic browser fixture. Use a
fresh detached service directory for public state and record an actual cutover
separately from candidate acceptance. No force pushes or paid external agents.

Data metadata and object bytes use separate authorities. Access must be derived
from current readable post references, not a stale upload flag. Keep object effects
outside retried data transactions and preserve submitted input on optimistic
conflicts. Do not weaken exact Host, Origin or CSRF checks to make a test pass.

Authored browser tests under tests/browser are optional development tools. Their
Node/Playwright dependency is not an application dependency. Keep installations,
fixtures, generated graphs, binaries, unreviewed screenshots, logs and credentials
ignored. The small reviewed synthetic set in docs/screenshots is an explicit
exception; never publish real-user data, credentials, or operator information.
Use installed free tools; do not launch Codex tasks, Codex CLI or paid APIs.

Read docs/CHECKPOINT.md for accepted source/test evidence, docs/ENGLISH-READING.md
for UX and media boundaries, and docs/RELEASE.md when a verified public release has
been recorded. Media HEAD is deliberately unsupported until the native runtime
can express representation metadata independently of a response body.

The user requires hosting through the Coder workspace. The canonical entry is
its existing public port 8793, not a dedicated custom-domain tunnel; consult
docs/CODER-HOSTING.md. Both dedicated Cloudflare tunnel units are stopped and
disabled. Do not reintroduce them through old systemd Wants/After dependencies.
The custom domain is only a read-redirect alias. Keep the exact Coder Host/Origin
checks and native session/CSRF validation. Source/run selection and live routing
evidence remain separate authorities.

The community UX release uses narrow first-party browser scripts for transfer,
preference delivery, post-card navigation, and confirmation dialogs. These are not
an alternative application server. Keep CSS and both script assets byte-identical
to their authored web files. Read docs/COMMUNITY-UX.md for private tags, the public
avatar exception, bounded search, 4 MiB transfers, and no-script boundaries.
Use tests/ux/run.sh via the normal browser command for current acceptance; the
older tests/browser flow suites retain historical UI assumptions and are not the
current release gate. Do not claim every historical suite was rerun.

## Quiet workflow contract

Read docs/QUIET-WORKFLOWS.md for the current writing and navigation model. Keep
Attach file and Post as the new-post actions, with no exposed draft collection,
saving notice, preview step, or routine warning about lost unsaved input. Owned
working copies remain an internal part of attachment and conflict recovery.
More contains secondary destinations and service information; Settings contains
actual settings. The mobile dock is Home, Post, Notifications, More.

Keep cursor trails bounded and destination-free. Preserve the exact reading place
(e.g. bookmarks, not the saved URL name) through reaction forms. File options must
return directly to the owned editor. HTTP(S) links remain natively escaped and
new-tab safe, and reply metrics must not count unreadable/deleted/muted records.
The SNS textinput module owns its 16,000-byte normalization boundary; do not
reintroduce the web-editor sample's unrelated 4 KiB admission cap.

Service-information pages must match implemented behavior. Do not invent legal
identity details, retention periods, automatic account deletion/export, or a
claim of legal compliance. Read docs/OPERATOR-RESPONSIBILITIES.md for operator
requirements that cannot be established by software or policy prose alone.

## Shared brand contract

Use icons::brand for all desktop/mobile/error brand links and icons::links for
their document heads. Never reintroduce a separate lk/ text glyph or text-only
error-page logo. The six-asset catalog and native manifest use one content
revision; read docs/SHARED-BRAND.md. Preserve the approved source SVG and actual
user profile images. Icon data uses compact hexadecimal constants and a bounded native decoder,
not higher runtime/review limits. The brand suite and public read-only contract
check the same image references and actual browser decoding.
