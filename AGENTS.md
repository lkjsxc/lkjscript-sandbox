# lkjscript-sandbox

This public monorepo contains independent projects under projects/. The lkjscript language implementation belongs in its separate repository.

Read the selected project's AGENTS.md and README.md before changing it. Use the project's pinned runtime; do not force all projects onto one toolchain. Root tooling must remain a small dispatcher and repository checks, not a game framework.

The owner authorized publishing this new repository. This does not authorize exporting old private Git history, runtime data, browser keys, credentials, internal deployment records, or unrelated projects. Preserve the existing Traffic City development checkout and running preview; creating or changing this repository is not a deployment. Do not configure a remote in the old standalone checkout.

Work in the relevant project only. Preserve useful behavior and user data, run relevant tests, and use lkjsxc for ordinary commits and pushes. Never force-push or discard unrelated work. Keep generated build/runtime/evidence/tools directories out of Git. Review publication content and secret-scan before pushing. Do not claim a native build or test passed unless it ran on the selected sources.
